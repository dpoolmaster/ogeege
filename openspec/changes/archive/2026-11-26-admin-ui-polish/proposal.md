## Why

Админка (Vue SPA `web/admin`) функционально работает, но выглядит неопрятно: базовый шрифт Pico раздут fluid-типографикой до ~21px, поля форм крупные и с двойными отступами, навигация свалена в один flex-ряд внутри узкой колонки, а заголовки слипаются с формами. Методисту неудобно и неприятно работать с большим объёмом контента.

## What Changes

- Базовая типографика админки фиксируется на 14px вместо fluid-роста Pico; уплотняются отступы форм, таблиц и заголовков.
- Навигация превращается в вертикальную липкую колонку со списком пунктов и подсветкой активного раздела.
- Появляется верхняя панель (`<header>`): название, email и роль пользователя, выход.
- Формы выравниваются корректно: поля и кнопки без двойных `margin-bottom`, кнопки прижаты к низу ряда.
- Контентная область ограничивается по ширине и получает ровные отступы.
- Пересобирается `web/admin/dist` (сборка встроена в Go-бинарь через `go:embed`).

Поведение API, маршруты, права и данные не меняются — изменение чисто визуальное.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

Нет. Изменение не меняет наблюдаемое поведение системы, только оформление административного интерфейса. В `.openspec.yaml` установлен `skip_specs: true`.

## Impact

- `web/admin/src/style.css` — переписывается визуальная тема и раскладка.
- `web/admin/src/App.vue` — новый каркас: `<header>` + боковая навигация со списком.
- `web/admin/dist/*` — пересборка через `npm run build` (встроена в бинарь через `go:embed`).
- Backend, API, миграции, зависимости Go и npm не затрагиваются.
