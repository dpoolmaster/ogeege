## ADDED Requirements

### Requirement: Проверка задания на лендинге трека

Система SHALL позволять посетителю без регистрации проверить ответ на одно опубликованное задание прямо на лендинге трека. Задание MUST быть опубликованным, публичным и поддерживать автоматическую проверку. Проверка MUST показывать вердикт и краткое объяснение и MUST NOT сохранять ответ в историю или связывать его с учётной записью. Изменяющий запрос MUST требовать CSRF-токен и MUST подчиняться ограничению частоты. Правила проверки и эталонный ответ MUST NOT раскрываться до отправки ответа.

#### Scenario: Верный ответ на лендинге

- **WHEN** посетитель вводит верный ответ в блок проверки на лендинге трека
- **THEN** результат «верно» и краткое объяснение показываются на той же странице

#### Scenario: Неверный ответ на лендинге

- **WHEN** посетитель вводит неверный ответ в блок проверки на лендинге трека
- **THEN** результат «неверно», корректный ответ и краткое объяснение показываются на той же странице

#### Scenario: Нет подходящего задания

- **WHEN** у трека нет опубликованного задания с автоматической проверкой
- **THEN** блок проверки не показывается, а лендинг остаётся доступным

#### Scenario: Ответ не сохраняется

- **WHEN** проверка задания на лендинге завершена
- **THEN** ответ не сохраняется в историю и не связывается с учётной записью

#### Scenario: Отправка без JavaScript

- **WHEN** JavaScript отключён и посетитель отправляет ответ на лендинге
- **THEN** проверка выполняется обычной отправкой формы с CSRF-токеном

## MODIFIED Requirements

### Requirement: Публичные лендинги треков

Система SHALL строить публичный лендинг для каждого опубликованного трека по его коду и MUST NOT требовать отдельного маршрута для конкретного предмета. Лендинг MUST содержать описание трека, структуру экзамена, ссылку на демо-диагностику, призыв к регистрации и блок проверки задания, если у трека есть подходящее опубликованное задание. Прежние адреса лендингов MUST перенаправляться на канонический адрес соответствующего трека. Неопубликованный или неизвестный трек MUST возвращать ошибку «не найдено».

#### Scenario: Публикация нового трека

- **WHEN** публикуется трек с новым кодом
- **THEN** его лендинг становится доступен по адресу, построенному от кода, без изменения кода приложения

#### Scenario: Прежний адрес лендинга

- **WHEN** посетитель открывает прежний адрес лендинга
- **THEN** он перенаправляется на канонический адрес соответствующего трека

#### Scenario: Неопубликованный или неизвестный трек

- **WHEN** посетитель открывает лендинг неопубликованного или неизвестного трека
- **THEN** возвращается ошибка «не найдено»

#### Scenario: Структура экзамена на лендинге

- **WHEN** у опубликованного трека есть опубликованный учебный год
- **THEN** лендинг показывает структуру экзамена и призыв к регистрации

#### Scenario: Блок проверки на лендинге

- **WHEN** у опубликованного трека есть задание с автоматической проверкой
- **THEN** лендинг показывает задание, поле ответа и кнопку проверки

### Requirement: Демо-диагностика

Система SHALL предоставлять демо-диагностику из 5–7 публичных заданий в пошаговом виде: одно задание на экран, индикатор прогресса и переход между шагами с сохранением введённых ответов. Результат MUST показываться без регистрации и MUST содержать итог и разбивку по темам. Полный отчёт MUST быть доступен после регистрации. Результат демо MUST NOT сохраняться как учебная сессия. Данные демо MUST быть ограничены по времени и MUST отклоняться при истечении или изменении. Навигация по шагам MUST работать без JavaScript.

#### Scenario: Запуск демо-диагностики

- **WHEN** посетитель запускает демо-диагностику по опубликованному треку
- **THEN** он получает от 5 до 7 публичных заданий

#### Scenario: Пошаговое прохождение

- **WHEN** посетитель заполняет ответ и переходит к следующему шагу
- **THEN** открывается следующее задание, а номер шага и общее число заданий видны на экране

#### Scenario: Возврат к предыдущему шагу

- **WHEN** посетитель возвращается к предыдущему шагу демо-диагностики
- **THEN** ранее введённый ответ сохраняется в поле

#### Scenario: Результат без регистрации

- **WHEN** посетитель отправляет ответы демо-диагностики
- **THEN** показывается итог и разбивка по темам без входа в систему

#### Scenario: Призыв к полному отчёту

- **WHEN** показан результат демо-диагностики
- **THEN** посетителю предлагается регистрация для получения полного отчёта

#### Scenario: Результат не сохраняется

- **WHEN** демо-диагностика завершена
- **THEN** результат не создаёт учебную сессию и не сохраняется в историю

#### Scenario: Истёкшие или изменённые данные демо

- **WHEN** данные демо-диагностики истекли или были изменены
- **THEN** проверка отклоняется с понятной ошибкой

#### Scenario: Навигация без JavaScript

- **WHEN** JavaScript отключён
- **THEN** переход между шагами и завершение демо-диагностики выполняются обычными формами и ссылками

### Requirement: Кэширование публичных страниц

Система SHALL кэшировать успешные ответы публичных GET-страниц на 60 секунд по ключу URL для анонимных посетителей. Аутентифицированные запросы MUST NOT получать общий кэш. Формы на закэшированной странице MUST оставаться работоспособными: CSRF-токен MUST подставляться при выдаче. Ошибочные ответы MUST NOT кэшироваться. Ответы HTMX-фрагментов проверки и шагов демо MUST NOT кэшироваться общим кэшем.

#### Scenario: Повторный запрос

- **WHEN** анонимный посетитель повторно запрашивает ту же страницу в пределах 60 секунд
- **THEN** ответ берётся из кэша

#### Scenario: Истечение кэша

- **WHEN** 60 секунд истекли
- **THEN** страница формируется заново

#### Scenario: Аутентифицированный запрос

- **WHEN** запрос содержит действующую сессию
- **THEN** общий кэш не используется

#### Scenario: CSRF на закэшированной странице

- **WHEN** закэшированная страница содержит форму
- **THEN** выданный CSRF-токен действителен для отправки формы

#### Scenario: Ошибка не кэшируется

- **WHEN** публичная страница возвращает ошибку
- **THEN** такой ответ не кэшируется

#### Scenario: Фрагмент не кэшируется

- **WHEN** запрашивается HTMX-фрагмент проверки ответа или шага демо
- **THEN** ответ не попадает в общий кэш страниц
