# 10. MVP и roadmap

Приоритеты: **P0** — критично для запуска, **P1** — важно, **P2** — желательно, **P3** — позже.
Сложность: **XS** (1–2 дня), **S** (3–5), **M** (1–2 недели), **L** (3–4 недели), **XL** (1–2 месяца).
Оценки ориентировочные для команды 3–5 человек.

---

### MVP: что можно упростить
- Один платёжный провайдер (карта + СБП), без рассрочки.
- Один тип задания (тест + текстовый ответ), без MathType.
- Тренажёр — базовые карточки без интервального алгоритма (простые статусы).
- Геймификация — уровни/опыт/баланс без сложных ачивок.
- Публичный сайт — 5–7 ключевых страниц, без банка заданий.
- Уведомления — e-mail + in-app, push позже.
- Админка — минимальные CRUD + загрузка видео/материалов.

## 4. Roadmap (ориентировочно)

```
Месяц 1-2:  Auth, профиль, онбординг, справочники
Месяц 2-4:  Каталог, продукты, тарифы, корзина, checkout (sandbox)
Месяц 4-6:  Обучение (курсы/занятия/плеер), ДЗ базово
Месяц 6-7:  Тренажёр, прогресс, геймификация базово
Месяц 7-8:  Публичный сайт, лид-формы, документы
Месяц 8-9:  Админка (CRUD), уведомления, стабилизация
────────── MVP ──────────
Месяц 10-12: Подписки/автопродление, промокоды/комплекты
Месяц 12-14: Проверка ДЗ/куратор, чат, реферал
Месяц 14-16: Банк заданий/пробники, аналитика, мобильный web
Месяц 16-18: AI-проверка, генерация вариантов, родительский кабинет
```

## 5. Критические зависимости MVP

1. Справочники (классы/предметы/типы курсов) → каталог.
2. Продукты/тарифы → корзина → оплата → доступ.
3. Доступ к продукту → занятия → ДЗ → прогресс → геймификация.
4. Роли/админка → создание контента.
5. Уведомления → удержание.

## 6. Риски roadmap

| Риск | Влияние | Митигация |
|---|---|---|
| Сложность платёжных интеграций/PCI | Высокое | Начать с одного провайдера/хостед-страницы |
| Объём контента (видео, задания) | Высокое | Поэтапный контент-план, импорт |
| Проверка ДЗ вручную не масштабируется | Высокое | AI-помощник + очередь кураторов |
| XSS в rich-редакторе | Высокое | Санитайз, CSP, allowlist |
| Потеря данных/платежей | Критическое | Идемпотентность, бэкапы, аудит |
| Низкая мотивация учеников | Среднее | Геймификация, напоминания |
| Юридические требования (ПД, лицензия) | Высокое | Документы, согласия, юрист |
| Стоимость SMS/видео | Среднее | Лимиты, кэш, CDN |
