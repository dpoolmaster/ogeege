# 06. UI-компоненты и дизайн-система

Наблюдения по `nd.umschool.net` (Vue 3 + собственные utility-классы `u-*`, компоненты `base-button`, `base-field`, `tab`), публичному `umschool.net` (Nuxt, блочный лендинг) и `id.umschool.net`.
Точные CSS-значения фиксируются только там, где они видны в DOM/классах. Остальное — визуальная оценка.

---

## 1. Layout LMS (desktop 1440×1000)

```
┌──────────────────────────────────────────────────────────────┐
│ Header 56px: логотип, промо, корзина, аватар, счётчики        │
├──────┬───────────────────────────────────────────────────────┤
│ Side │ Контент: max-width, отступы 20–40px                    │
│ bar  │ Заголовок H1/H2, вкладки, карточки, таблицы            │
│56px  │                                                       │
│(→272)│                                                      │
└──────┴───────────────────────────────────────────────────────┘
```

- **Sidebar:** `width: 56px`, при hover/раскрытии — `272px`, фиксирован слева, `top: 56px`, `bottom: 0`, фон `grey-50`.
- **Header:** высота 56px, фиксирован, содержит хлебные крошки/логотип, промо-баннер, иконку корзины (`icon-cart`), аватар (`profile-menu-trigger-button`), счётчики.
- **Content:** скроллируемая область `scroll-area`, секции с `rounded-xl`, отступами 20–40px.
- **Модалки/дроверы:** overlay `[data-testid=overlay]`, фиксированный, `z-overlay`, закрытие по Escape/клику.
- **Popmechanic:** сторонний слой `z-index: 100000000`, паранойя на весь экран; перекрывает UI.

## 2. Типографика

- Шрифт: `Co Fo Gothic VF` (woff2), системный fallback.
- Utility-классы: `u-text-2xs-medium`, `u-text-xs-medium`, `u-text-sm-normal`, `u-text-md-medium`, `u-text-md-semibold`, `u-text-lg-medium`, `u-text-xl-semibold`, `u-text-2xl-semibold`.
- Заголовки: `text-xl-medium`, `text-xl-semibold`, `text-2xl-semibold`.
- Числа/счётчики: `text-md-medium`, `text-lg-semibold`.
- Вторичный текст: `u-text-grey-500/600/700`.

## 5. Кнопки

Компонент `base-button`.

Варианты (по классам):
- `standard primary` — основная заливка.
- `outlined secondary` — обводка.
- `light` — светлая.
- `plain standard-opacity` — без фона (иконки).
- `standard-opacity`.

Состояния: default, hover, active, disabled (`disabled` + opacity), loading (спиннер внутри), selected.
Примеры: «Получить консультацию», «Перейти к оплате», «Начать», «Завершить», «Сохранить», «Скопировать».

---

## 6. Поля ввода

Компонент `base-field` / `base-field-control`.

- Текстовое поле: label сверху, placeholder, сообщение об ошибке снизу, `field-clear-button` (крестик), `field-control-container`.
- Пароль: тип `password`, кнопка показа (не проверено).
- Телефон: маска `+7 (000) 000-00-00`, селектор страны (Россия/Беларусь/Казахстан).
- Чекбокс: кастомный `togglable-native-control` (скрытый input + визуальный переключатель), label.
- Радио: `input[type=radio]` + карточка/строка.
- Select: кастомный dropdown (не `<select>`), опции с чекбоксами/радио.
- Rich-редактор: панель инструментов (жирный, курсив, индексы, выравнивание, шрифт, изображение, файл, ссылка, видео, MathType/ChemType, отмена/повтор), контентная область.
- Поиск: поле с иконкой, «Отменить поиск», «Очистить поиск».

---

## 7. Табы

Компонент `tab` (`data-testid=tab`), underline-индикатор.

- Активный: `data-tab-selected="true"`, `u-text-grey-900`, полоса `u-bg-primary`.
- Неактивный: `u-text-grey-700`, полоса `u-opacity-0`.
- Используется в профиле («Основные сведения / Документы»), прогрессе («График / Темы / Номера КИМ / Пробные варианты»), ДЗ (номера 1..N), достижениях.
- Наблюдение: клики по табам прогресса иногда не переключали контент; вероятно, требуется точное попадание/данные.

## 10. Модальные окна и поповеры

Наблюдаемые модалки:
- «Подтверждение номера» (телефон).
- «Подключаем Вконтакте» (VK ID).
- «Ник в чате» (инпут + правила + «Сохранить»).
- «Тренировка завершена» (+50 ОП, «Перейти на главную»).
- «Завершить тестирование?» (предупреждение о незавершённых заданиях).
- «Выбор тарифа» (карточка тарифа).
- «Завершить домашнее задание?» (подтверждение).
- «Удалить всё» (подтверждение очистки корзины).
- Popmechanic-попап: «ВЕБЫ ИДУТ БЕЗ ТЕБЯ», таймер, «Записаться» (Telegram-бот).
- Push-модалка: «Хотите получать уведомления?».
- Onboarding-подсказки: «Тренажёр — лучшая практика…», «Дедлайны не ждут!», «Есть вопросы?…».

Поповеры: счётчики медалей/умкоинов/серии; меню профиля; выбор месяца в календаре; фильтры.

## 11. Уведомления/тосты

- Тосты об успехе/ошибке (например, «Пароль успешно изменён», «Не удалось загрузить…»).

## 12. Прогресс-индикаторы

- «Шкала успеха 0/2» на странице занятий.
- EXP-шкала «0 / 250 ОП до следующего уровня».

## 14. Адаптивность

- Breakpoints в классах: `tablet`, `tablet-lg`, `desktop` (точные px не раскрыты; ориентировочно 768/1024/1280).
- Мобильный viewport 390×844:
  - боковая панель скрыта, бургер открывает меню;
  - карточки в одну колонку;
  - на расписании компактная неделя (видны 2 дня в тесте);
  - фильтры ДЗ/занятий открываются кнопкой «Фильтры»;
  - таблицы превращаются в карточки/скролл.
- Публичный сайт: мобильное меню «Открыть меню сайта», липкий header.

---

## 15. Доступность (предварительно)

- Есть `aria-current="page"` у активного пункта меню.
- Тренажёр поддерживает клавиши ← →.
- Часть кастомных контролов (плитки, чекбоксы) не является нативными input, что может ухудшать доступность.
- Фокус-стили присутствуют (`focus:u-text-grey-600`), но полный аудит не проводился.
- Контраст не измерялся.

---

## 16. Отличия публичного сайта

- Блочная Tilda/Nuxt-верстка: hero, сетки преимуществ, видео-истории, отзывы, FAQ-аккордеоны, лид-формы.
- Липкий header с меню и CTA «Выбрать предметы».
- Формы: `full_name`, `phone`, `email` (опционально), чекбокс согласия, honeypot.
- Публичные страницы содержат SEO-тексты, хлебные крошки, JSON-LD (на предметных страницах).
- Промо-попапы и таймеры (Popmechanic) агрессивны и перекрывают контент.
