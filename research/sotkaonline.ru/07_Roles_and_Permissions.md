# 07. Роли и права доступа

> Внимание: вживую исследована только роль **Guest** (публичный сайт). Роли ЛК восстановлены по коду/API и помечены как INFERRED. Матрица — рабочая гипотеза для реализации, а не подтверждённые права исходной платформы.

## 1. Обнаруженные роли

| Роль | Признак | Подтверждение | Статус |
|---|---|---|---|
| Guest | нет сессии | публичный сайт | CONFIRMED |
| Student | `is_trial=false`, есть storeAccess | ЛК, nav | INFERRED |
| Trial student | `is_trial=true` | nav lockedRole, `/trial` | OBSERVED |
| Tutor | `is_tutor=1` | nav `notShownRole:["isTutor"]`, `/tutors/register` | OBSERVED |
| Teacher | `/teacher/*` | API teacher auth | INFERRED |
| Parent | `/parent/statistic/*` | API | INFERRED |
| Mentor | `chat` «наставник», review | API `/study/review/to-mentor` | INFERRED |
| Curator | упоминания куратора в лендинге | текст | INFERRED |
| Support | `/moz` | nav | INFERRED |
| Admin | `admin.sotkaonline.ru` | API-домен | NOT_AVAILABLE |

## 2. Признаки и флаги пользователя

| Флаг | Смысл | Влияние |
|---|---|---|
| `is_trial` | пробный доступ | блокировки разделов |
| `is_tutor` | тьютор | скрытие «Обучение», «Расписание» |
| `is_active` | активный тьютор | доступ к ЛК |
| `has_tutor` / `hasTutorProduct` | тьютор-продукт | «Чат с тьютором» |
| `isHighSchool` | старшие классы | «Чат поддержки» |
| `isMiddleLow` | младшие классы | «Контрольные» вместо «Пробников» |
| `isZeroYearType`, `grade_8` | 8 класс | «Контрольные» |
| `grade` | класс 1–11 | упрощённое меню ≤8 |
| `year_type` | тип года | доступность продуктов |
| `isProfessionsMode` | режим профессий | только «Мои предметы» |
| `has_tariff_restrictions` | ограничения тарифа | запрет отправки наставнику |

## 5. Ограничения доступа (наблюдаемые)

1. Все защищённые маршруты редиректят на `/auth` без сессии (CONFIRMED).
2. Trial-пользователь видит заглушки вместо Главной/Домашек/Пробников/Библиотеки (OBSERVED).
3. Тьютор не видит «Обучение» и «Расписание» (OBSERVED).
4. Младшие классы (≤8) не видят «Статистику», «Библиотеку», «Банк заданий» в меню (OBSERVED).
5. «Чат поддержки» доступен только старшим классам (`isHighSchool`) (OBSERVED).
6. Отправка наставнику блокируется при `has_tariff_restrictions` (OBSERVED).
7. Смена преподавателя доступна только на курсах с `can_change_teacher` (OBSERVED).
8. Дуэли/зачёты — только Про/Про+ (CONFIRMED по матрице тарифов).

## 6. Что нужно уточнить

- Как родитель привязывается к ребёнку (код/инвайт/телефон)?
- Может ли родитель оплачивать и управлять подпиской ребёнка?
- Разграничение mentor/tutor/curator.
- Права преподавателя: только свои курсы или все?
- Существует ли несколько ролей у одного пользователя.
- Как реализован админ-доступ (2FA, IP-ограничения).
