# 00. Обзор продукта — Сотка (sotkaonline.ru)

## 1. Краткое резюме

**Сотка** — российская онлайн-школа и технологическая платформа подготовки к ЕГЭ, ОГЭ, олимпиадам и школьным предметам (5–8, 1–4 классы). Продукт combines:

- **маркетинговый сайт** (`sotkaonline.ru`) — лендинги, тарифы, магазин, блог, учебник, банк заданий, ГДЗ, страницы преподавателей;
- **закрытую LMS-платформу** (`platform.sotkaonline.ru`) — личный кабинет ученика: курсы, уроки, домашки, пробники, расписание, статистика, чат с наставником, дуэли, магазин, достижения, реферальная программа;
- **систему продаж** (`sotkaonline.ru/sotkastore`) — конфигуратор тарифа и оформление доступа (в т.ч. рассрочка/оплата частями);
- **дополнительные направления** — олимпиады, «Нокаут» (интенсив), курсы по профессиям, B2B, «Помоги школе», профориентация.

Тип продукта: **EdTech / LMS / subscription SaaS** с сильной геймификацией и пакетной моделью «4 предмета по цене 1».

## 3. Ценностное предложение (по публичным страницам)

- 4 предмета в одном тарифе вместо оплаты за каждый предмет.
- 2–3 преподавателя на предмет + 100-балльные преподаватели, возможность смены.
- Доступ к платформе до 11 класса без доплат за годы (для 8/9/10 классов).
- Домашки с проверкой, пробники с ручной проверкой, банк заданий, библиотека.
- Геймификация: соткакоины, ачивки, прогресс-бар, страйки, дуэли, тамагочи.
- Наставник/куратор и комьюнити.
- Гарантия поступления на бюджет в тарифе «Про+» (по оферте).
- Бонусные курсы по ИИ/UGC/вайбкодингу с «вечным» доступом.

Источники: главная, `/about`, `/about/tariffs`, `/about/questions`, `/for-parents`, `/professions`, `/nokaut`, `/b2b`. Статус: **CONFIRMED** (тексты страниц).

## 5. Ключевые пользовательские пути

1. **Покупка**: лендинг → тариф/магазин → выбор класса → выбор 1–4 предметов → выбор тарифа → контакты (имя, телефон, email, VK) → промокод → оплата/рассрочка → создание доступа.
2. **Вход**: телефон или российская почта → код по SMS/письму → ЛК.
3. **Онбординг**: имя → цель → фокусные предметы → текущие баллы пробников → контакты → персональный план.
4. **Обучение**: главная/план → теория (видео) → тест → практика (вебинар) → домашка → проверка (авто/наставник) → статистика.
5. **Пробники**: `/samples` → пробник → ответы → ручная проверка → результат.
6. **Геймификация**: действия → соткакоины/ачивки/страйки → магазин/тамагочи.
7. **Дуэли**: выбрать предмет → старт → подбор соперника → тест → результат/история.
8. **Реферал**: ссылка → приглашение друга → бонус → вывод на карту через 30 дней.
9. **Поддержка**: чат с наставником/тьютором, чат поддержки, апелляции на оценки.

## 6. Монетизация (наблюдаемая)

- Пакетная подписка на 4 предмета, помесячно или на учебный год.
- Тарифы: Базовый / Стандарт / Про / Про+ / Бюджет (0 ₽ сейчас, оплата при поступлении на бюджет).
- Помесячные цены (2026/2027, grade 11): 3 600 / 3 990 / 5 790 / 9 790 ₽.

Источник: `/about/tariffs`, API `store/sotka-products`, `/sotkastore`. Статус: **CONFIRMED** для публичных цен.

## 7. Объём и ограничения исследования

### Что подтверждено
- Публичная навигация, карта сайта (sitemap, 300 URL + 539 URL учебника).
- Тарифы и цены, конфигуратор магазина, поля оформления.
- Форма входа и валидации (пустое поле, иностранная почта, несуществующий пользователь).
- Бесплатный банк заданий: выбор предмета/темы/варианта, ответ, показ правильного ответа, прогресс.
- Учебник, блог, ГДЗ, страницы преподавателей, FAQ, документы, B2B, родители, олимпиады, младшие классы.

### Чего не удалось подтвердить
- **Личный кабинет не исследован вживую**: в окружении нет авторизованной сессии; самостоятельная регистрация недоступна — аккаунт создаётся только при покупке. Вход по `doncity@mail.ru` вернул `422 «Пользователь не найден.»`.
- Поэтому все экраны ЛК описаны по **публичному JS-бандлу и API-маршрутам** (OBSERVED/INFERRED), а не по фактическому прохождению сценариев.
- Не проверены: реальные платежи, рассрочка, возвраты, дуэли, магазин, тамагочи, реферальные выплаты, чат, уведомления, роли родителя/тьютора.

### Ограничения
- Не выполнялись платежи и действия, создающие обязательства.
- Не использовались скрытые API для доступа к чужим данным.
- Публичный `/statistics/:id` при неверном id показывает «Произошла ошибка» — валидные публичные отчёты не перебирались.

## 9. Главный вывод для команды

Продукт состоит из двух контуров: **публичный контентно-продающий сайт** и **закрытая LMS с сильной геймификацией**. Для запуска аналога критичны:

1. Каталог курсов/предметов и привязка доступа к оплаченному пакету.
2. Плеер уроков (видео + статья + тест) и прогресс.
3. Домашки с автопроверкой и ручной проверкой наставником, апелляциями.
4. Пробники и статистика.
5. Расписание и чат.
6. Подписки/доступы и платежи.
7. Геймификация (коины, ачивки, дуэли, страйки) — как дифференциатор, но не обязательна для MVP.
