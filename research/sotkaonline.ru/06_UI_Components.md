# 06. UI, дизайн-система и компоненты

> Публичная часть описана по фактическим экранам (CONFIRMED). Компоненты ЛК — по JS/CSS-бандлу (OBSERVED/INFERRED).

## 1. Общая структура страниц

### Публичный сайт
```
Header (лого, мега-меню, «Купить», «Войти»)
  ├── Мега-меню: ЕГЭ / ОГЭ / Олимпиады / 5-8 / 1-4 / Другие / О нас / Тарифы
Hero (H1, подзаголовок, CTA)
Контентные секции (карточки, тарифы, отзывы, FAQ, лид-форма)
Footer (4 колонки ссылок + юр. данные)
Cookie-баннер
```

### Платформа (ЛК)
```
AppShell
  ├── Sidebar (Главная, План, Обучение, Расписание, Ещё)
  ├── Header (лого, баланс коинов, уведомления, аватар/профиль)
  ├── Content (outlet)
  └── Floating-элементы (тамагочи, прогресс, чат)
```

## 2. Типографика и цвета (OBSERVED)

- **Шрифты:** `PPRightGrotesk-Medium`, `GraphikLCG-Medium` (preload в HTML).
- **Базовый синий:** `#1455FF` (из SVG-иконок), градиент hero `#386dff → #d5e0ff`.
- **Цвета предметов (из JS):**

| Предмет | Цвет |
|---|---|
| Профильная математика | `rgba(16,169,255,1)` |
| Английский | `rgba(255,111,59,1)` |
| Химия | `rgba(180,20,255,1)` |
| Биология | `rgba(0,215,45,1)` |
| История | `rgba(248,53,53,1)` |
| Литература | `rgba(0,212,218,1)` |
| Русский | `rgba(109,41,255,1)` |
| Обществознание | `rgba(62,128,255,1)` |

- **Фон предмета:** тот же цвет с alpha `0.06`.
- **Радиусы:** `--mantine-radius-x4` (магазин), скругления карточек 16–24 px (визуально).
- **Тени:** мягкие, карточки с бордерами.

## 4. Состояния экранов

| Состояние | Пример | Реализация |
|---|---|---|
| Empty | «Пока нет уведомлений», «Список пуст», «Предметы не найдены» | Заглушка + иллюстрация |
| Loading | «Сохранение…», скелетоны | Спиннер/скелетон |
| Error | «Произошла ошибка», «Не удалось загрузить…» | Текст + повтор |
| Success | «Ответ сохранён», «Зачёт сдан», «План выполнен» | Тост/бейдж |
| Disabled | «Далее» при 0 предметов, недоступный тариф | disabled + tooltip |
| Locked | Разделы для trial | `lockedLabel` + картинка |
| Expired | «Подписка закончилась» | Баннер + CTA |
| Validation | «Это обязательное поле», «Некорректная почта» | Inline-ошибка |
| Unauthorized | Редирект на `/auth` | Роутер |
| Conflict | «Пользователь с данной почтой привязан к другому телефону» | Модалка/ошибка |

## 5. Адаптивность

- **Breakpoint:** `max-width: 1024px` — переключение мобильной навигации (из JS `(max-width: 1024px)`).
- Мобильное меню: «Обучение»/«Чаты» вместо бокового.
- Скрытие части пунктов для младших классов (`grade < 9`).
- Публичные страницы адаптированы под мобильные (лендинги, магазин).
- Видео/плеер — адаптивный (INFERRED).

## 6. Доступность (наблюдаемое)

- ARIA-роли у компонентов Mantine (`role="dialog"`, `role="listbox"`, `role="checkbox"`, `aria-live`).
- Кнопки с `aria-label` (слайдер).
- Фокус-стили (Mantine).
- Alt у изображений (частично).

## 7. Рекомендации для аналога

1. Использовать единый дизайн-токен-слой (цвета, радиусы, тени, типографика).
2. Разделить компоненты на `ui/` (атомы) и `features/` (доменные).
3. Обязательно проектировать состояния empty/loading/error/locked для каждого экрана.
4. Для геймификации — отдельные компоненты (CoinBadge, StreakCalendar, AchievementCard).
5. Для длинных списков — виртуализация и скелетоны.
6. Мобильная навигация — bottom bar или drawer (в Сотке — drawer/меню).
