- **Уверенность:** CONFIRMED.

- **Уверенность:** OBSERVED.

### PRICE-007. Промокоды

## 2. Доступ и подписки

### SUB-001. Доступ = storeAccess
- **Описание:** доступ к курсам хранится как `storeAccess` с датами и продуктом.
- **API:** `GET /profile/storeAccesses`, `/profile/subscriptions`.
- **Уверенность:** INFERRED.

### SUB-002. Статусы подписки
- **Статусы (OBSERVED):** активна; закончилась; подходит к концу (порог в днях); «невозможно продлить».
- **Правило:** при `diffDays < 0` — «Подписка закончилась»; иначе активна.
- **Источник:** код `subscriptions` (diff по дням).
- **Уверенность:** INFERRED.

### SUB-003. Продление
- **Триггер:** «Продлить подписку».
- **Условие:** `canRenew` / `canUpdate` у продукта.
- **Действие:** `POST /store/renew`, `/store/checkRenew`.
- **Исключение:** «Невозможно продлить эту подписку».
- **Уверенность:** INFERRED.

### SUB-004. Смена набора предметов
- **Действие:** `POST /store/updateAccess`, `/store/checkUpdate`, `/store/addCoursesToAccesses`, `/store/checkAddCourses`.
- **Уверенность:** INFERRED.

### SUB-005. Пробный доступ (trial)
- **Признак:** `is_trial`.
- **Ограничения:** блокируются Главная, Домашки, Пробники, Библиотека; доступен «План знакомства», часть курсов.
- **Источник:** nav `lockedRole`, тексты.
- **Уверенность:** INFERRED.

### SUB-006. Смена тарифа
- **Правило (публичное):** тариф можно поменять, предупредив персонального помощника; платы за отмену нет.
- **Источник:** FAQ главной.
- **Уверенность:** CONFIRMED (декларация), механика UNKNOWN.

## 3. Обучение и прогресс

### PROG-001. Зачёт теории
- **Правило:** теория засчитывается, если просмотрен видеоурок (полностью).
- **Источник:** текст статистики.
- **Уверенность:** INFERRED.

### PROG-002. Зачёт практики
- **Правило:** практика/онлайн-занятие засчитывается, если выполнена домашняя работа.
- **Источник:** текст статистики.
- **Уверенность:** INFERRED.

### PROG-003. Глубина просмотра
- **API:** `POST /course/{id}/lesson/{lessonId}/video-depth`, `/life-depth`.
- **Правило:** прогресс видео/урока сохраняется по мере просмотра.
- **Уверенность:** INFERRED.

### PROG-004. Открытие практики
- **Правило:** «Пройди теорию, чтобы открыть практику» — практика заблокирована до прохождения теории.
- **Источник:** UI расписания/курса.
- **Уверенность:** INFERRED.

### PROG-005. План на день
- **Правило:** план формируется из непройденных уроков, пропущенных блоков, работы над ошибками; «Осталось с прошлых дней».
- **Уверенность:** INFERRED.

### PROG-006. Персональный план
- **Правило:** интенсивность зависит от целевого балла и доступного времени; фокусные предметы идут первыми.
- **Источник:** онбординг.
- **Уверенность:** INFERRED.

### PROG-007. Зачёты
- **Правило:** индивидуальный зачёт по блоку/теме; результат «Зачёт сдан».
- **API:** `GET /course/{id}/block/{blockId}/final-test`.
- **Уверенность:** INFERRED.

## 4. Домашние задания

### HW-001. Типы заданий
- **Типы ответов:** `string`, развёрнутый ответ, тест, загрузка файла (INFERRED).
- **Признаки:** `answer_type`, `is_home_work`, `mandatory`, `right_answers`, `score`.
- **Источник:** публичный API банка заданий (структура аналогична).
- **Уверенность:** OBSERVED.

### HW-002. Обязательные/необязательные
- **Правило:** `mandatory=true` — обязательный вопрос; иначе необязательный.
- **Уверенность:** OBSERVED (поля API).

### HW-003. Режим min/max
- **Правило:** пользователь выбирает минимальный (обязательный) или максимальный (дополнительный) объём ДЗ.
- **Источник:** описание тарифов.
- **Уверенность:** INFERRED.

### HW-004. Автопроверка
- **Правило:** тесты проверяются автоматически; развёрнутые ответы — вручную.
- **Источник:** тексты «Задания с развёрнутым ответом не проверяются автоматически».
- **Уверенность:** INFERRED.

### HW-005. Ручная проверка
- **Правило:** развёрнутые ответы можно отправить наставнику; проверка с экспертной оценкой; срок зависит от нагрузки.
- **API:** `/study/review`, `/study/review/to-mentor`.
- **Уверенность:** INFERRED.

### HW-006. Апелляция
- **Правило:** можно подать апелляцию на оценку задания с комментарием; статус апелляции отображается.
- **API:** `POST /homework/{id}/answers/{answerId}/appeal`.
- **Уверенность:** INFERRED.

### HW-007. Самопроверка
- **Правило:** пользователь выставляет балл по критериям, затем «Подвести итоги».
- **Уверенность:** INFERRED.

### HW-008. Дедлайны
- **Правило:** у ДЗ есть дедлайн; уведомления `homework_deadline_today`, `homework_deadline_1d`.
- **Уверенность:** INFERRED.

### HW-009. Сброс ответов
- **Правило:** можно сбросить ответы (все или по тегу).
- **API:** `/homework/{id}/answers/reset`, `/tag-reset`.
- **Уверенность:** INFERRED.

## 7. Геймификация

### GAME-001. Соткакоины
- **Правило:** начисляются за выполненные задания, занятия, прогресс-бар; внутренняя валюта, не деньги.
- **Источник:** описание тарифов, магазин.
- **Уверенность:** CONFIRMED (декларация), формула UNKNOWN.

### GAME-002. Ачивки
- **Правило:** достижения за действия (знакомство с платформой, 10 тем и т.п.).
- **Уверенность:** INFERRED.

### GAME-003. Прогресс-бар
- **Правило:** заполняется за занятия и ДЗ; за заполнение — коины.
- **Уверенность:** INFERRED.

### GAME-004. Страйки (ударный режим)
- **Правило:** ежедневная регулярность; календарь страйка; сброс при пропуске (INFERRED).
- **Источник:** «Ударный режим с системой страйков», `daily_strike_completed`, `week_strike_completed`.
- **Уверенность:** OBSERVED.

### GAME-005. Система жизней
- **Правило:** доступна на Про/Про+; влияет на количество коинов.
- **Уверенность:** CONFIRMED (декларация).

### GAME-006. Тамагочи
- **Правило:** питомца нужно кормить/лечить; при игнорировании болеет и не приносит монеты; есть заморозка.
- **API:** `buy-freeze`, `enable`, `disable`, `treat-effect`, `treat-weakness`.
- **Уверенность:** INFERRED.

### GAME-007. Магазин
- **Правило:** товары за коины, лимит «1 шт. в руки», наличие, избранное, тарифные ограничения.
- **Уверенность:** INFERRED.

### REF-001. Вознаграждение

- **Источник:** UI `/referral`.

- **Правило:** на банковскую карту; доступно через 30 дней после оплаты приглашённым; «Доступно для вывода сегодня».

- **Уверенность:** INFERRED.

### REF-003. Антифрод

- **Уверенность:** UNKNOWN.

## 10. Гарантия и возвраты

### GUAR-001. Гарантия поступления (Про+)
- **Правило:** при выполнении условий (выбрать направления, заниматься весь год по системе) — гарантия поступления на бюджет; иначе возврат денег; закреплено в договоре.
- **Источник:** главная, `/about/tariffs`, оферта.
- **Уверенность:** CONFIRMED (декларация), условия — UNKNOWN.

### REFUND-001. Возврат
- **Правило:** регулируется офертой; API `refund/*` относится к реферальным выплатам, не к возвратам за обучение (INFERRED).
- **Уверенность:** UNKNOWN.

## 11. Ограничения и защита

### LIM-001. Не более 4 предметов
- **Правило:** «Можно выбрать не больше 4 предметов».
- **Источник:** магазин, онбординг.
- **Уверенность:** CONFIRMED.

### LIM-002. Российская почта
- **Правило:** авторизация только с российскими почтовыми адресами (№199-ФЗ).
- **Источник:** форма входа.
- **Уверенность:** CONFIRMED.

### LIM-003. Один аккаунт на телефон/почту
- **Правило:** почта не может быть привязана к другому телефону.
- **Источник:** FAQ магазина.
- **Уверенность:** CONFIRMED (декларация).

### LIM-004. Тарифные ограничения
- **Правило:** часть функций (`has_tariff_restrictions`) недоступна на младших тарифах (например, отправка наставнику).
- **Источник:** код проверки `!n?.has_tariff_restrictions`.
- **Уверенность:** OBSERVED.
