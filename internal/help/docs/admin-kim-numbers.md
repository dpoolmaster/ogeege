# Номера КИМ

Раздел задаёт структуру экзаменационного варианта: перечень номеров заданий (КИМ) для конкретного учебного года с указанием части, типа ответа и максимального первичного балла.

## Поля

- **ID учебного года** — год, к которому относится номер.
- **Номер** — номер задания в варианте.
- **Часть** — номер части экзамена (1 — краткий ответ, 2 — развёрнутый).
- **Тип ответа** — `short` (краткий, автопроверка) или `extended` (развёрнутый, проверка методистом).
- **Макс. балл** — максимальный первичный балл за номер.
- **Заголовок** — необязательное пояснение к номеру.

## Действия

- **Фильтр** — показывает номера выбранного учебного года.
- **Создать** — добавляет номер КИМ к учебному году.
- **Удалить** — удаляет номер, если к нему не привязаны задания.

## Ограничения

- Номер в рамках учебного года должен быть уникальным.
- Максимальный балл должен быть положительным.
- Удаление номера с заданиями запрещено: сначала перенесите или удалите задания.
