# Варианты

Раздел собирает варианты для диагностики, практики и пробников. Вариант состоит из набора заданий с баллами и имеет ограничение по времени.

## Поля

- **ID учебного года** — год, к которому относится вариант.
- **Название** — отображаемое название варианта.
- **Вид** — `diagnostic` (диагностика), `practice` (практика) или `mock` (пробник).
- **Минуты** — длительность прохождения, используется серверным таймером.
- **Задания вручную** — JSON-массив `{"task_id", "points"}` для ручной сборки.
- **Правила генерации** — JSON-массив `{"kim_number_id", "count", "difficulty", "topic_id"}` для автоматической сборки.
- **Статус** — `draft` или `published`.

## Действия

- **Создать вручную** — собирает вариант из указанных заданий.
- **Сгенерировать** — подбирает задания по правилам и создаёт вариант.
- **Опубликовать** — делает вариант доступным ученикам.

## Ограничения

- Все задания варианта должны относиться к выбранному учебному году.
- Для генерации должно хватать подходящих опубликованных заданий, иначе вариант не создаётся.
- JSON-массивы заданий и правил должны быть корректными.
- Опубликованный вариант нельзя пересобрать — создайте новый.
