# Теория

Раздел управляет версиями теоретического материала по темам. Каждая версия — отдельный документ в Markdown; активной для учеников становится опубликованная версия.

## Поля

- **Тема** — иерархический список тем, сгруппированных по трекам; вложенные темы показаны с отступом.
- **Содержание** — текст в Markdown, редактируется визуальным редактором.
- **Статус** — `draft` или `published`.
- **Версия** — номер версии, увеличивается при создании новой версии.

## Действия

- **Выбрать тему** — при выборе темы автоматически загружается список версий, а в редактор подставляется текст активной (опубликованной) версии. Выбранная тема сохраняется в адресе страницы (`?topic_id=...`), поэтому после обновления страницы она остаётся выбранной.
- **Загрузить версии** — показывает все версии выбранной темы.
- **Открыть версию** — клик по строке версии подставляет её текст в редактор для просмотра или создания новой версии на её основе.
- **Создать версию** — сохраняет новую черновую версию на основе введённого текста.
- **Сохранить изменения** — изменяет текст выбранной черновой версии без создания новой. Доступно только для версий в статусе `draft`.
- **Опубликовать** — делает версию активной для учеников.

## Ограничения

- Для загрузки и создания версии обязателен выбор темы.
- Формулы LaTeX должны быть сбалансированы, иначе сохранение отклоняется.
- Опубликованную версию нельзя изменить — для правок создайте новую версию.
- Одновременно активна только одна опубликованная версия темы.
