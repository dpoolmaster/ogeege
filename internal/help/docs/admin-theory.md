# Теория

Раздел «Теория» ведёт теоретические материалы по темам. Каждая тема может иметь несколько версий документа, а ученикам показывается действующая опубликованная версия. Текст хранится в Markdown, редактируется визуальным редактором и поддерживает формулы LaTeX.

Теория привязана к теме, а не к учебному году или номеру КИМ. Поэтому один и тот же материал используется во всех вариантах, где встречается эта тема.

## Где используется теория

| Место | Что берётся из теории |
|---|---|
| Страницы теории для ученика | Текст действующей опубликованной версии темы. |
| Карточка темы и разбор ошибок | Ссылка на теоретический материал по теме. |
| План подготовки | Материал для повторения темы. |
| Публичные SEO-страницы | Опубликованная теория доступна в публичном контуре. |

Если у темы нет опубликованной версии, ученик не увидит теоретический материал, даже если теория сохранена как черновик.

## Что подготовить перед созданием

1. **Трек** — создаётся в разделе «Треки».
2. **Тема** — создаётся в разделе «Темы» и принадлежит треку. Именно тема выбирается в этом разделе.

В интерфейсе тема выбирается из иерархического списка, сгруппированного по трекам. Вложенные темы показаны с отступом. Идентификатор темы — UUID; вручную вводить его не нужно, он подставляется из выбранного пункта. Выбранная тема сохраняется в адресе страницы (`?topic_id=...`), поэтому после обновления страницы выбор не теряется.

## Поля версии

| Поле | Обязательно | Что указывать |
|---|---|---|
| **Тема** | Да | Тема трека, к которой относится материал. |
| **Содержание** | Да | Текст в Markdown. Редактируется визуальным редактором. |
| **Версия** | — | Назначается автоматически: следующая после максимальной версии темы. |
| **Статус** | — | `draft` или `published`. |
| **Кто изменил** | — | Заполняется автоматически текущим пользователем. |

Пустой текст (в том числе состоящий только из пробелов) не принимается: вернуть ошибку «поле обязательно».

## Версии и статусы

| Статус | Что означает | Видят ли ученики |
|---|---|---|
| `draft` | Черновик версии. Можно свободно редактировать. | Нет |
| `published` | Опубликованная версия. Участвует в выборе действующей. | Да, если это действующая версия |
| `archived` | Архив. Зарезервирован в схеме, через интерфейс не выставляется. | Нет |

Версии нумеруются подряд для каждой темы:

- первая версия темы получает номер `1`;
- каждая следующая — `максимальная версия + 1`.

Номер версии не переиспользуется и не уменьшается.

Действующая версия — это опубликованная версия темы с наибольшим номером. Важно понимать:

- опубликовать можно несколько версий одной темы; интерфейс не снимает с публикации предыдущую;
- если опубликованы версии 1 и 2, ученикам показывается версия 2;
- если после этого опубликовать старую версию 1, действующей всё равно останется версия 2;
- отдельной кнопки «снять с публикации» нет;
- вернуть опубликованную версию в черновик через интерфейс нельзя.

Практический вывод: чтобы исправить опубликованный материал, создайте новую версию с исправлениями и опубликуйте её. Она станет действующей, а старая останется в истории.

## Действия

### Выбрать тему

Выберите тему в списке. Список сгруппирован по трекам, внутри — по иерархии тем. При выборе автоматически:

1. загружается список версий темы (от новых к старым);
2. в редактор подставляется текст действующей опубликованной версии;
3. тема записывается в адрес страницы.

Кнопка «Загрузить версии» повторяет загрузку для текущей темы.

### Открыть версию

Клик по строке в таблице версий подставляет текст этой версии в редактор. Строка подсвечивается как выбранная. Это режим просмотра и основа для новой версии: изменение текста в редакторе не меняет версию автоматически.

### Создать версию

Кнопка «Создать версию» сохраняет текущий текст редактора как новую черновую версию темы. Действует так:

- версия создаётся всегда в статусе `draft`;
- номер версии — следующий для выбранной темы;
- исходная версия (если вы её открыли) не изменяется;
- содержимое берётся из редактора, а не из открытой строки таблицы.

Поэтому типичный сценарий правки опубликованного материала: выберите тему → откройте действующую версию → отредактируйте текст → «Создать версию» → «Опубликовать».

Создать версию без выбранной темы нельзя.

### Сохранить изменения

Кнопка «Сохранить изменения» видна только тогда, когда выбрана версия в статусе `draft`. Она изменяет текст этой же черновой версии, не создавая новую и не меняя номер версии.

Для опубликованной версии кнопки нет: опубликованные версии неизменяемы. Попытка изменить их через API вернёт конфликт.

### Опубликовать

Кнопка «Опубликовать» доступна для любой версии, кроме уже опубликованной. Перед публикацией сервер проверяет сбалансированность формул LaTeX. После публикации:

- версия получает статус `published`;
- если её номер больше, чем у других опубликованных версий темы, она становится действующей для учеников;
- если номер меньше, версия опубликована, но действующей не станет.

Опубликовать можно как черновик, так и архивную версию (если она когда-либо получила такой статус через API).

## Редактор и Markdown

Содержание редактируется визуальным редактором. Он сохраняет текст в Markdown, поэтому в итоговом материале поддерживаются:

- заголовки, списки, таблицы, цитаты;
- выделение текста, ссылки, изображения;
- блоки кода;
- формулы LaTeX в `$...$` и `$$...$$`.

Формулы проверяются при каждом создании, изменении и публикации:

- парные `$` и `$$` должны быть закрыты;
- фигурные скобки `{` и `}` должны быть сбалансированы;
- `\begin{...}` должно иметь парный `\end{...}`;
- `\left` должно иметь парный `\right`;
- пустая формула (например, `$ $`) недопустима.

Если формула не проходит проверку, версия не сохраняется. Исправьте формулу и повторите действие.

При показе ученику Markdown преобразуется в HTML и очищается по allowlist: опасные теги и обработчики удаляются. Это защита от вставки скриптов через текст теории.

## Список версий

Таблица показывает все версии выбранной темы: номер версии, статус и кнопку публикации. Версии отсортированы от новой к старой. Фильтров и пагинации в интерфейсе нет: показываются все версии темы.

Текст версии в таблице не выводится. Чтобы увидеть его, откройте строку — текст появится в редакторе.

## Ограничения

- Тема должна существовать; иначе вернуть ошибку «тема не найдена».
- Содержание обязательно и не может быть пустым.
- Формулы LaTeX должны быть сбалансированы.
- Опубликованную версию нельзя изменить — создайте новую.
- Удаления версий в интерфейсе нет.
- Номер версии уникален внутри темы.
- Действующей считается опубликованная версия с наибольшим номером; одновременно могут быть опубликованы несколько версий.

## Частые ошибки

| Сообщение | Причина | Что сделать |
|---|---|---|
| «тема не найдена» | Темы с таким ID нет. | Выберите тему из списка. |
| «content_md: поле обязательно» | Текст пустой или состоит из пробелов. | Напишите текст материала. |
| «statement_md: пустая формула LaTeX» | Есть `$ $` без содержимого. | Удалите пустую формулу или заполните её. |
| «statement_md: несбалансированные скобки в формуле LaTeX» | Не закрыта `{` или `}`. | Проверьте парность скобок. |
| «statement_md: несбалансированные окружения LaTeX» | Не совпадают `\begin{...}` и `\end{...}`. | Закройте окружение. |
| «statement_md: несбалансированные \left и \right» | Есть `\left` без `\right` или наоборот. | Сделайте пары. |
| «изменить опубликованную версию теории: конфликт данных» | Попытка сохранить изменения в опубликованной версии. | Создайте новую версию и опубликуйте её. |
| «некорректный идентификатор» | Некорректный ID темы или версии. | Выберите тему из списка; обновите страницу. |

Поле ошибки в сообщениях про формулы называется `statement_md`, хотя речь идёт о содержании теории. Это внутреннее имя поля проверки формул; ориентируйтесь на текст после двоеточия.

## Чек-лист перед публикацией

- [ ] Выбрана нужная тема.
- [ ] Текст написан и не пустой.
- [ ] Все формулы LaTeX закрыты и корректны.
- [ ] Таблицы и списки отображаются как задумано.
- [ ] Изображения и ссылки ведут куда нужно.
- [ ] Версия создана заново, а не изменена поверх опубликованной.
- [ ] После публикации версия стала действующей (её номер больше предыдущих опубликованных).
