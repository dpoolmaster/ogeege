# Рубрики

Раздел задаёт критерии проверки развёрнутых ответов (часть 2). Рубрика привязывается к номеру КИМ и учебному году и версионируется.

## Поля

- **ID номера КИМ** — номер задания, для которого заданы критерии.
- **ID учебного года** — год, к которому относится рубрика.
- **Критерии** — JSON-массив `{"code", "description", "max_points"}`.
- **Версия** — номер версии рубрики.
- **Статус** — `draft` или `published`.

## Действия

- **Создать** — сохраняет черновую рубрику с критериями.
- **Изменить** — загружает критерии выбранной рубрики в редактор.
- **Сохранить новую версию** — создаёт новую версию на основе отредактированных критериев.
- **Опубликовать** — делает версию действующей для проверки.

## Ограничения

- Критерии должны быть корректным JSON-массивом.
- Сумма максимальных баллов критериев должна соответствовать максимальному баллу номера КИМ.
- Код критерия уникален в рамках рубрики.
- Одновременно активна только одна опубликованная версия для пары «номер КИМ + учебный год».
