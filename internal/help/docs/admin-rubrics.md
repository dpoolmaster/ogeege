# Рубрики

Раздел «Рубрики» задаёт критерии проверки развёрнутых ответов части 2. Рубрика привязана к паре «номер КИМ + учебный год» и версионируется: каждое изменение создаёт новую версию, а старые остаются в истории.

Рубрика нужна для заданий, у которых `answer_spec` имеет `kind: "extended"`. По ней работает проверка части 2: AI готовит черновик с баллами по критериям, методист подтверждает или исправляет результат. Без опубликованной рубрики проверить развёрнутый ответ по критериям нельзя.

## Где используется рубрика

| Место | Что берётся из рубрики |
|---|---|
| Проверка части 2 | Список критериев и максимальные баллы по каждому. |
| AI-черновик проверки | Критерии передаются в промпт, ответ AI раскладывается по кодам критериев. |
| Очередь методиста | Методист видит критерии и выставленные баллы. |
| Апелляции | Проверяется, по каким критериям снижен балл. |
| Результат сессии | Сумма баллов по критериям даёт первичный балл за задание. |

## Что подготовить перед созданием

1. **Учебный год** — создаётся в разделе «Учебные годы».
2. **Номер КИМ** — создаётся в разделе «Номера КИМ», должен принадлежать выбранному учебному году, иметь часть 2 и тип ответа `extended`.
3. **Максимальный балл номера КИМ** — сумма баллов критериев рубрики должна точно совпадать с этим значением.

Идентификаторы (`ID номера КИМ`, `ID учебного года`, `ID рубрики`) — UUID. В таблице рубрик ID не выводится; ID рубрики возвращается API при создании и в списке.

Сервер проверяет существование номера КИМ, совпадение года и сумму баллов, но не проверяет часть и тип ответа номера. Номер части 2 с типом `extended` выбирайте сами: рубрика для номера части 1 не будет использоваться при проверке.

## Поля рубрики

| Поле | Обязательно | Что указывать |
|---|---|---|
| **ID номера КИМ** | Да | UUID номера задания части 2. |
| **ID учебного года** | Да | UUID года. Номер КИМ должен принадлежать этому году. |
| **Критерии** | Да | JSON-массив критериев. |
| **Версия** | — | Назначается автоматически: следующая после максимальной версии для этой пары «номер КИМ + год». |
| **Статус** | — | `draft` или `published`. |

### Критерий

Каждый критерий — объект:

```json
{
  "code": "C1",
  "description": "Обоснованно получен верный ответ",
  "max_points": 2
}
```

| Поле | Обязательно | Что указывать |
|---|---|---|
| `code` | Да | Короткий код критерия, например `C1`. Уникален внутри рубрики. |
| `description` | Нет | Формулировка критерия для методиста и ученика. Может быть пустой. |
| `max_points` | Да | Максимальный балл по критерию. Положительное целое число. |

Пример полной рубрики для номера КИМ с максимальным баллом 3:

```json
[
  {"code": "C1", "description": "Верно построена математическая модель", "max_points": 1},
  {"code": "C2", "description": "Верно выполнены преобразования", "max_points": 1},
  {"code": "C3", "description": "Получен верный ответ", "max_points": 1}
]
```

## Версии и статусы

| Статус | Что означает | Используется при проверке |
|---|---|---|
| `draft` | Черновик версии. | Нет |
| `published` | Опубликованная версия. | Да, если это последняя опубликованная версия для пары «номер + год» |
| `archived` | Архив. Через интерфейс не выставляется. | Нет |

Версия создаётся автоматически:

- первая рубрика для пары «номер КИМ + год» получает версию `1`;
- каждая следующая — `максимальная версия + 1`.

Действующей считается опубликованная версия с наибольшим номером для пары «номер КИМ + год». Старые опубликованные версии остаются в базе, но проверка берёт самую новую из них.

Важно: если изменить опубликованную рубрику, новая версия сразу создаётся опубликованной. Если изменить черновик, новая версия останется черновиком. Отдельной кнопки «снять с публикации» нет.

## Действия

### Создать

1. Укажите ID номера КИМ и ID учебного года.
2. Вставьте JSON-массив критериев.
3. Нажмите «Создать».

Создаётся новая версия в статусе `draft`. Если для пары «номер + год» уже есть рубрики, версия будет следующей.

### Изменить

Кнопка «Изменить» в строке рубрики загружает её критерии в поле редактирования и запоминает выбранную рубрику. Поля «ID номера КИМ» и «ID учебного года» при этом не меняются: новая версия создаётся для той же пары.

### Сохранить новую версию

Кнопка появляется после нажатия «Изменить». Она создаёт новую версию рубрики с отредактированными критериями:

- если исходная версия была `draft`, новая версия тоже `draft`;
- если исходная версия была `published`, новая версия сразу `published` и становится действующей.

Старые версии не удаляются и не изменяются.

### Опубликовать

Кнопка «Опубликовать» доступна для версий в статусе, отличном от `published`. Перед публикацией сервер повторно проверяет критерии. После публикации версия становится действующей, если её номер больше, чем у ранее опубликованных.

## Ограничения

- Критерии должны быть корректным JSON-массивом; в интерфейсе JSON разбирается до отправки.
- Массив критериев не может быть пустым.
- Код критерия обязателен и не должен повторяться внутри рубрики.
- Максимальный балл каждого критерия должен быть положительным.
- Сумма `max_points` всех критериев должна точно совпадать с максимальным первичным баллом номера КИМ.
- Номер КИМ должен существовать и принадлежать указанному учебному году.
- Версия для пары «номер КИМ + год» уникальна.

## Список рубрик

В таблице видны версия, ID номера КИМ и статус. Список показывает до 200 записей, все версии подряд, без фильтров в интерфейсе.

API поддерживает фильтры `kim_number_id`, `exam_year_id`, `status` и курсорную пагинацию. Отдельную версию рубрики можно получить запросом `GET /admin/rubrics/{id}`, если известен ID версии; в интерфейсе детальный просмотр не выведен.

## Частые ошибки

| Сообщение | Причина | Что сделать |
|---|---|---|
| «номер КИМ не найден» | Несуществующий ID номера. | Проверьте ID в разделе «Номера КИМ». |
| «номер КИМ принадлежит другому учебному году» | Номер относится к другому году. | Исправьте год или номер. |
| «критерии обязательны» | Пустой массив. | Добавьте хотя бы один критерий. |
| «код критерия обязателен» | У критерия пустой `code`. | Заполните код. |
| «код критерия повторяется» | Два критерия с одинаковым `code`. | Сделайте коды уникальными. |
| «максимальный балл критерия должен быть положительным» | `max_points` меньше или равен нулю. | Укажите положительное число. |
| «сумма баллов критериев N не совпадает с максимальным баллом номера КИМ M» | Сумма критериев не равна баллу номера. | Пересчитайте критерии под максимальный балл номера КИМ. |
| «Проверьте заполнение полей» | Некорректный JSON или UUID. | Проверьте синтаксис JSON и формат идентификаторов. |

## Чек-лист перед публикацией

- [ ] Номер КИМ относится к части 2 и типу ответа `extended`.
- [ ] Учебный год совпадает с годом номера КИМ.
- [ ] Коды критериев уникальны.
- [ ] Сумма `max_points` равна максимальному баллу номера КИМ.
- [ ] Формулировки критериев понятны методисту.
- [ ] Новая версия действительно должна заменить предыдущую.
