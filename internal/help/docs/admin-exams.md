# Треки

Раздел управляет учебными треками платформы: ОГЭ математика, ЕГЭ математика (профиль) и ЕГЭ математика (база). Трек — верхний уровень контента, к нему привязываются учебные годы и темы.

## Поля

- **Код** — короткий латинский идентификатор трека, например `oge_math`. Должен быть уникальным.
- **Название** — отображаемое название трека на сайте.
- **Предмет** — предметная область, например `math`.
- **Статус** — `draft` (черновик) или `published` (опубликован).

## Действия

- **Создать** — добавляет новый трек в статусе черновика.
- **Опубликовать** — делает трек доступным в публичном контуре. Кнопка показывается только для неопубликованных треков.
- **Удалить** — удаляет трек, если он не используется связанными данными.

## Ограничения

- Опубликованный трек нельзя удалить, пока на него ссылаются учебные годы и темы.
- Код трека после создания менять не рекомендуется: на него опираются импорт и фильтры.
- Удаление и публикация фиксируются в журнале аудита.
