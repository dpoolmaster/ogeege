# Аудит

Раздел доступен только администратору. Он показывает журнал действий в админке: кто, когда и что изменил.

## Поля

- **ID актора** — идентификатор пользователя, совершившего действие.
- **Действие** — тип операции, например создание или публикация.
- **Объект** — тип и идентификатор изменённой сущности.
- **С RFC3339**, **По RFC3339** — границы периода в формате RFC3339.
- **Время**, **Актор**, **Действие**, **Объект**, **IP** — колонки журнала.

## Действия

- **Фильтр** — загружает до 100 записей журнала по заданным условиям.

## Ограничения

- Раздел доступен только роли `admin`; методист получает отказ.
- Журнал только для чтения: записи нельзя изменить или удалить через интерфейс.
- Даты фильтра должны быть в формате RFC3339, иначе фильтр их не применит.
