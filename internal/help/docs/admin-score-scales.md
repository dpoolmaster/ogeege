# Шкалы перевода

Раздел «Шкалы перевода» задаёт соответствие между первичным баллом и итоговым результатом для конкретного учебного года. Для ОГЭ и ЕГЭ (база) итог — оценка 2–5, для ЕГЭ (профиль) — тестовый балл 0–100. Шкала применяется при подсчёте результатов диагностики, практики и пробников.

Шкала хранится как набор строк: одна строка на каждый возможный первичный балл. Сохранение заменяет шкалу года целиком, поэтому перед изменением загрузите текущую шкалу, отредактируйте её и сохраните.

## Где используется шкала

| Место | Что берётся из шкалы |
|---|---|
| Результат сессии | Первичный балл переводится в тестовый балл или оценку. |
| Статистика прогресса | Итоговый балл для графиков и сравнений. |
| Прогноз балла | Ожидаемый первичный балл переводится по шкале. |
| Пробники и диагностика | Итог показывается ученику и родителю. |

Если шкала для года не заполнена, платформа не сможет корректно перевести первичный балл в итоговый результат.

## Что подготовить

1. **Учебный год** — создаётся в разделе «Учебные годы».
2. **Номера КИМ года** — создаются в разделе «Номера КИМ» и имеют максимальный первичный балл.
3. **Максимальный первичный балл года** — сумма максимальных баллов всех номеров КИМ этого года. Шкала должна покрывать диапазон от `0` до этого значения включительно.

Пример: если у года номера КИМ в сумме дают 31 балл, шкала должна содержать ровно 32 строки — для первичных баллов `0, 1, 2, …, 31`.

Идентификатор учебного года — UUID. В интерфейсе он вводится вручную в поле «ID учебного года».

## Поля шкалы

| Поле | Обязательно | Что указывать |
|---|---|---|
| **ID учебного года** | Да | UUID года, для которого задаётся шкала. |
| **entries** | Да | JSON-массив строк перевода. |

### Строка шкалы

```json
{
  "primary_score": 0,
  "test_score": 0,
  "grade": 2,
  "min_threshold": null
}
```

| Поле | Обязательно | Что указывать |
|---|---|---|
| `primary_score` | Да | Первичный балл. Неотрицательное целое число. |
| `test_score` | Да | Тестовый балл. Неотрицательное целое число. |
| `grade` | Нет | Оценка от 1 до 5 или `null`, если для трека важнее тестовый балл. |
| `min_threshold` | Нет | Необязательное целое число — служебная отметка минимального порога. Сохраняется как есть. Если не уверены, оставьте `null`. |

`min_threshold` не участвует в текущем автоматическом расчёте результата. Он сохраняется вместе со строкой и может использоваться для отображения и проверок порога. Не заполняйте его произвольными значениями без методического указания.

## Пример

Для года с максимальным первичным баллом 5 нужны строки для баллов от 0 до 5:

```json
[
  {"primary_score": 0, "test_score": 0, "grade": 2, "min_threshold": null},
  {"primary_score": 1, "test_score": 0, "grade": 2, "min_threshold": null},
  {"primary_score": 2, "test_score": 0, "grade": 3, "min_threshold": null},
  {"primary_score": 3, "test_score": 0, "grade": 3, "min_threshold": null},
  {"primary_score": 4, "test_score": 0, "grade": 4, "min_threshold": null},
  {"primary_score": 5, "test_score": 0, "grade": 5, "min_threshold": null}
]
```

Для профиля с тестовым баллом вместо оценки:

```json
[
  {"primary_score": 0, "test_score": 0, "grade": null, "min_threshold": null},
  {"primary_score": 1, "test_score": 4, "grade": null, "min_threshold": null},
  {"primary_score": 2, "test_score": 8, "grade": null, "min_threshold": null}
]
```

## Действия

### Загрузить

1. Введите ID учебного года.
2. Нажмите «Загрузить».

В поле редактирования появится текущая шкала года в виде JSON-массива. Если шкалы ещё нет, будет пустой массив `[]`. Загрузка только читает данные и ничего не меняет.

### Сохранить

1. Отредактируйте JSON-массив.
2. Нажмите «Сохранить».

Сервер проверяет набор и в одной транзакции удаляет старую шкалу года и записывает новую. Если проверка не прошла, старая шкала остаётся без изменений.

Кнопка «Сохранить» недоступна, пока не указан ID учебного года.

## Ограничения

- Массив `entries` не может быть пустым.
- Учебный год должен существовать.
- Шкала должна содержать ровно `максимальный первичный балл года + 1` строку.
- `primary_score` должен покрывать весь диапазон от `0` до максимального балла без пропусков и повторений. Порядок строк в JSON не важен: сервер сортирует их сам.
- `test_score` не может быть отрицательным.
- `grade` может быть `null` или целым числом от 1 до 5.
- Сервер не проверяет, что `test_score` и `grade` не убывают с ростом первичного балла. Следите за монотонностью вручную: с ростом первичного балла итоговый результат не должен уменьшаться.
- Сохранение заменяет шкалу целиком. Отдельной операции «изменить одну строку» нет.
- Уже сохранённые результаты прошлых попыток не пересчитываются: шкала применяется к новым расчётам.

## Частые ошибки

| Сообщение | Причина | Что сделать |
|---|---|---|
| «некорректный идентификатор» | Пустой или невалидный ID учебного года. | Проверьте UUID года. |
| «учебный год не найден» | Такого года нет. | Проверьте ID в разделе «Учебные годы». |
| «шкала перевода обязательна» | Пустой массив `entries`. | Добавьте строки шкалы. |
| «шкала не покрывает первичный балл N» | Пропущен один из первичных баллов. | Добавьте строку для каждого балла от 0 до максимума. |
| «шкала должна покрывать первичные баллы от 0 до N» | Строк меньше или больше, чем нужно. | Приведите число строк к `N + 1`. |
| «тестовый балл не может быть отрицательным» | `test_score` меньше нуля. | Укажите 0 или больше. |
| «оценка должна быть от 1 до 5» | `grade` вне диапазона. | Исправьте оценку или поставьте `null`. |
| «Проверьте заполнение полей» | Некорректный JSON. | Проверьте синтаксис массива и объектов. |

## Чек-лист перед сохранением

- [ ] ID учебного года верный.
- [ ] Шкала загружена перед редактированием, а не собрана с нуля по памяти.
- [ ] Строки покрывают первичные баллы от 0 до максимального без пропусков.
- [ ] Количество строк равно максимальному первичному баллу года плюс один.
- [ ] Для ОГЭ и базы заполнена оценка 2–5 (допустимы значения от 1 до 5).
- [ ] Для профиля заполнен тестовый балл 0–100.
- [ ] Итоговые значения не убывают с ростом первичного балла.
- [ ] Значения сверены с официальной шкалой перевода.
