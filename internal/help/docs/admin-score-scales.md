# Шкалы перевода

Раздел задаёт шкалу перевода первичных баллов в тестовые баллы и оценку для конкретного учебного года. Шкала применяется при подсчёте результатов пробников и диагностики.

## Поля

- **ID учебного года** — год, для которого задаётся шкала.
- **entries** — JSON-массив строк перевода:
  - `primary_score` — первичный балл;
  - `test_score` — тестовый балл;
  - `grade` — оценка;
  - `min_threshold` — минимальный порог (может быть `null`).

## Действия

- **Загрузить** — показывает текущую шкалу выбранного учебного года.
- **Сохранить** — полностью заменяет шкалу года переданным набором строк.

## Ограничения

- Сохранение заменяет шкалу целиком, а не отдельные строки.
- Первичный балл в наборе не должен повторяться.
- Диапазоны должны быть непрерывными и возрастающими: тестовый балл и оценка не убывают с ростом первичного.
- JSON должен быть корректным, иначе сохранение отклоняется.
