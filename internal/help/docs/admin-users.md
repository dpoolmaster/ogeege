# Пользователи

Раздел доступен только администратору. Он позволяет находить учётные записи, менять роль и состояние пользователя.

## Поля

- **Поиск** — строка поиска по email или ID пользователя.
- **Email** — адрес учётной записи.
- **Роль** — `student`, `parent`, `methodist` или `admin`.
- **Статус** — `unverified`, `active`, `blocked` или `anonymized`.

## Действия

- **Найти** — загружает до 100 пользователей по строке поиска.
- **Сохранить** — применяет выбранные роль и статус к пользователю.

## Ограничения

- Раздел доступен только роли `admin`; методист получает отказ.
- Нельзя понизить собственную учётную запись, если это оставит систему без администраторов.
- Изменение роли и статуса фиксируется в журнале аудита.
- Блокировка (`blocked`) запрещает вход; анонимизация (`anonymized`) необратима.
