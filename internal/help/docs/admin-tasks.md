# Задания

Раздел ведёт банк заданий. Задание привязывается к учебному году и номеру КИМ, содержит условие, эталон ответа, сложность и статус публикации.

## Поля

- **ID учебного года**, **ID номера КИМ** — место задания в структуре экзамена (обязательны).
- **ID темы** — необязательная привязка к теме для диагностики и плана.
- **Сложность** — `easy`, `medium` или `hard`.
- **Источник**, **Ссылка на источник** — откуда взято задание.
- **Отображаемый ответ** — эталон ответа для показа ученику и методисту.
- **answer_spec JSON** — машинное описание ответа для автопроверки.
- **Условие** — текст задания в Markdown, редактируется визуальным редактором.
- **Статус** — `draft`, `published` или `archived`.
- **Версия** — номер версии задания.

## Действия

- **Фильтр** — по учебному году, номеру КИМ, статусу и поисковой строке.
- **Сохранить** — создаёт новое задание или изменяет выбранное (кнопка «Изменить»).
- **Опубликовать** — делает задание доступным для практики и пробников.
- **В архив** — снимает опубликованное задание с использования, сохраняя историю.
- **Удалить** — удаляет задание, если оно не используется в вариантах.
- **Импортировать** — пакетное создание заданий из JSON-массива.
- **Загрузить изображение** — прикрепляет изображение к заданию по его ID.

## Ограничения

- `answer_spec` должен быть корректным JSON и соответствовать типу ответа.
- Условие и источник обязательны.
- Импорт возвращает отчёт: создано, пропущено, отклонено.
- Удаление задания, входящего в варианты, запрещено — используйте архивирование.
