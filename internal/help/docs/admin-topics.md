# Темы

Раздел ведёт дерево тем трека. Темы используются для привязки заданий, построения карты пробелов и персонального плана подготовки. Список отображается иерархически: дочерние темы сдвинуты вправо относительно родительской.

## Поля

- **Трек** — выпадающий список треков, которому принадлежит тема.
- **Родительская тема** — необязательный выпадающий список тем выбранного трека для построения иерархии.
- **Код** — короткий уникальный идентификатор темы.
- **Название** — отображаемое название темы.
- **Порядок** — порядковый номер для сортировки в списках.

## Действия

- **Фильтр** — отбирает темы по треку, родительской теме и части кода. Родительская тема выбирается только после выбора трека и показывает её саму и всё поддерево.
- **Создать** — добавляет тему в дерево трека.
- **Удалить** — удаляет тему, если к ней не привязаны задания, теория и дочерние темы.

## Ограничения

- Код темы уникален в рамках трека.
- Нельзя удалить тему, у которой есть дочерние темы, задания или теория.
- Родительская тема должна принадлежать тому же треку.
